Groq APIキーの設定

このアプリはあなたのGroq APIキーで文字起こしします。キーは端末内にのみ保存され、外部には送信されません。

APIキーの取得方法

  1. console.groq.com/keys を開く
  2. アカウントでログイン（未登録なら新規登録）
  3. 「Create API Key」をクリックしてキーを作成
  4. 表示された gsk_ から始まるキーをコピーして下に貼り付け

Groq APIキー
